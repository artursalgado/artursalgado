## Sobre mim

Estudante de Engenharia Informática no IPVC e fundador da **[NovusCoding](https://www.novuscoding.pt)** — um estúdio de software em Portugal onde quem desenha é quem constrói. Faço software real, com clientes reais e em produção, entre aulas — sem aceleradoras, sem atalhos.

```text
🚀  NovusCoding   →  estúdio de software à medida, IA e jogos
🍽️  NovusRES      →  SaaS para restauração, no ar (5 restaurantes ativos) · NovusRES IA+ a caminho
🧠  Novus HQ      →  a plataforma que corre o estúdio por dentro — com IA e bot de Telegram
🎬  Cliente       →  Yann's Vizion  (site + plataforma de produção com IA)
🛡️  Cliente       →  NEURIS  (CTI — Proteção Civil e Defesa)
🏢  A construir   →  SEGREDO
🎓  Engenharia Informática — IPVC
```
